# SELQUARO

**Your purchases. Safely kept.** Receipt, document and warranty vault for Android and iOS.

SELQUARO starts with **zero accounts, zero pre-populated products and zero external servers**. It stores user-created purchase records and encrypted files locally, without ad networks or analytics.

## SELQUARO 0.2.0

- Premium dark-navy/cyan dashboard, searchable vault, product details, expiry timeline and security settings
- Save and edit real purchase dates, prices, categories, serial numbers, receipts and warranty documents
- Photograph receipts, import PDFs and images, extract Latin OCR on-device and verify values manually
- **View PDFs and photos inside the app** without unencrypted export; intentionally share a copy when needed
- AES-256-GCM encrypted storage with device Keystore/Keychain-protected random key
- Optional biometric/device passcode unlock
- **Opt-in local warranty notifications** 30, 7 and 1 days before user-supplied deadlines
- **Portable encrypted .sqvault backups** protected by a passphrase; restore into an empty vault
- No registration, sync, demo data, telemetry or network account features

## Android / iOS build

Flutter 3.47+ and Android Studio/Xcode required:

```bash
git clone https://github.com/bren-wp/SELQUARO.git
cd SELQUARO
bash tool/bootstrap_platforms.sh
flutter pub get
flutter analyze
flutter test
flutter build apk --release
flutter build appbundle --release
```

Android and iOS host projects are deterministically generated by `tool/bootstrap_platforms.sh`. This configures camera permissions, OS notification receivers, Android backup exclusion, OCR ProGuard rules, branding and iOS deployment minimum. A fresh clone requires the bootstrap step. Do not manually skip this step.

## Signing and releases

Version **0.2.0+2**. GitHub Actions builds Android APK/AAB and verifies an unsigned iOS build, then publishes a GitHub prerelease only on passing CI. Android CI artifacts are **test packages**, not upload-signed Google Play binaries. Official Android signing is not configured without a stable upload keystore. Apple Developer signing is required for IPA distribution.

## Privacy and limitations

Receipt files and records live encrypted within app private storage. Portable backup ciphertext can be shared by explicit user action, but its password **cannot be recovered**. Automatic Google Drive/iCloud sync is not included. The app asks notification permission only when enabling reminders.

Expiry dates must come from actual purchase/warranty terms; no legal durations are invented. Notification delivery can be affected by OS background policies. Keep original purchase receipts until backup/restore has been verified on your device.
