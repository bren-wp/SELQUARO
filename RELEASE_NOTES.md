# SELQUARO v0.1.0

Initial Android/iOS alpha featuring a private local purchase vault, encrypted attachments, editable warranty dates, on-device receipt recognition, search, and a dark mobile interface.

No accounts, advertising, analytics, seeded products, or cloud sync.

Android APK: testing only; Google Play requires permanent app-signing keys.
iOS: unsigned compilation is verified by CI. Distribution requires Apple Developer signing.
Expiry timeline is in-app; scheduled device notifications and portable backup are planned, not included.
